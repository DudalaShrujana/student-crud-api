# Student CRUD API

A REST API for managing student records using FastAPI and SQLite.

## Features
- Create student records
- Retrieve all students or one student by ID
- Update student records
- Delete student records
- Validate names, courses, and email addresses
- Prevent duplicate email addresses
- Handle missing records with appropriate errors
- Store records persistently using SQLite

## Technologies
- Python
- FastAPI
- SQLite
- Pydantic
- Uvicorn

## Prerequisites
- Python 3.10 or later
- pip
